# Documentación para el RAG

El agente `RAG_Researcher` consulta los documentos de esta carpeta. Se indexan los ficheros `.pdf`, `.txt`, `.md`, `.asl`, `.java` y `.html`.

Los documentos no se incluyen en el repositorio. Descarga aquí la documentación de Jason que quieras usar (por ejemplo, la de [jason-lang.github.io](https://jason-lang.github.io/)) y regenera el índice:

```bash
python update_rag.py
```
